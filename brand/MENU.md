## The Big 7 — Core Identity

These seven dishes ARE Diesel Delights. Every one has a Diesel name, a story,
and Vince's fingerprint. They're tied together by five house sauces — Diesel
Chili (DC), Diesel Hoisin (DH), Diesel Fish-Garlic, Diesel Fish Sauce, and
Diesel Peanut Sauce — each assigned to its plate. No guessing, no clutter.

**Every plate is $10.** One price. No confusion. Pull up, pick your
signature, eat. Fast ordering, insane value for chef-level food.

## Opening Strategy

### Phase 1 — Soft Open (Week 1–2)
Run all Big 7 from day one. That's the promise: seven signatures, all on,
all dialed. Prove the kitchen can execute every single one perfectly.

### Phase 2 — Dial & Grow (Week 3–4)
Listen to what people order most, tighten portion sizes and timing, add
sides if needed. Start posting food content daily.

### Phase 3 — The Vince Experience (Month 2+)
One night a week, limited seats, Vince cooks a 5-course set menu pulling
from the Big 7 plus chef-only dishes. This is where Michelin Vince lives —
inside Diesel Delights, not instead of it.

## Pricing Philosophy

**$10/plate. Every plate. Simple, clean, fast.**

| Why This Works | |
|----------------|---|
| **Fast ordering** | No price anxiety. Pick a number, eat. |
| **Volume** | Lower price = more plates out the window = more turns |
| **Repeat visits** | $10 is "I can eat here 3x a week" territory |
| **Perceived value** | Chef-level food at $10 makes people tell everyone |
| **Simple register** | 3 plates + 2 drinks = instant math, fast checkout |

| Scenario | Target Check | What They Order |
|----------|-------------|-----------------|
| Lunch solo | $10 – $13 | 1 plate + drink |
| Quick starter + main | $20 – $23 | Rolls + 1 plate + drink |
| Dinner for two | $25 – $30 | 2 plates + rolls + drinks |
| Group of four | $45 – $55 | 4 plates + rolls + drinks |
| Date night | $30 – $40 | Rolls + oysters + 1 plate + drinks |
| Vince Experience | $55 – $75/person | Premium set menu, the full chef journey |

At these prices you're undercutting every chain in the power center while
delivering ten times the soul. That's how you build a line out the door.
